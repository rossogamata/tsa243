### [Заняття 2.2 — Управління процесами, архівування та файлові права](lesson2_2/)

- `ps`, `top`, `htop` — моніторинг та керування процесами
- `kill`, `kill -9` — завершення процесів
- `tar` — створення та розпакування архівів
- `chmod` — права доступу (числовий запис)
- `ln -s` — символічні та жорсткі посилання

Включає скрипт [автоматичної перевірки](lesson2_2/самоперевірка/) виконаних завдань.

### [Заняття 3.3 — Робота з файловою системою Linux](lesson3_3/)

- `fdisk`, `parted`, `gdisk` — розмітка дисків (MBR/GPT)
- `mkfs`, `mkswap` — форматування розділів (ext4, xfs, FAT32, swap)
- `mount`, `umount`, `/etc/fstab` — монтування та автозапуск
- `df`, `du`, `lsblk`, `blkid` — моніторинг файлової системи
- `fsck`, `tune2fs`, `smartctl` — перевірка та діагностика

Включає інтерактивний скрипт [самоперевірки](lesson3_3/самоперевірка/check.sh).

### [Заняття 4.1 — Системне ПЗ: керування пакетами (Лекція)](lesson4_1/)

- **APT** (`apt update/install/remove/purge`) — пакетний менеджер Debian/Ubuntu
- **YUM/DNF** — пакетний менеджер RHEL/Fedora/CentOS
- Встановлення з вихідного коду: `./configure && make && make install`
- Спільні бібліотеки: `ldd`, `ldconfig`, `LD_LIBRARY_PATH`
- Текстові редактори: **nano**, **vim**, **VS Code + WSL Remote**
- Практичне завдання: встановлення Git у WSL

---

### [Заняття 4.2 — Системне ПЗ: дії з ПЗ (Практика)](lesson4_2/)

- Дослідження APT: `apt show`, `apt-cache depends/rdepends`, `dpkg -L/-S`
- Повний цикл: встановлення, перевірка, видалення (`remove` vs `purge`)
- Збірка **jq** з вихідного коду (`configure → make → make install`)
- Аналіз динамічних бібліотек: `ldd`, `ldconfig -p`
- Редактор **nano**: навігація, пошук, заміна, конфіг SSH
- Редактор **vim**: режими, навігація, пошук/заміна, мультирядкові операції
- Потокові редактори **sed** та **awk** для автоматизації

Включає інтерактивний скрипт [самоперевірки](lesson4_2/самоперевірка/check.sh) (7 розділів, 50+ питань).

## Швидка шпаргалка

```bash
# Процеси
ps aux                        # список процесів
kill -9 <PID>                 # примусове завершення
top / htop                    # моніторинг у реальному часі

# Архіви
tar -czvf archive.tar.gz dir/ # створити .tar.gz
tar -xzvf archive.tar.gz      # розпакувати

# Права доступу
chmod 740 file                # власник: rwx, група: r, інші: ---
ln -s target linkname         # символічне посилання

# Диски та файлова система
lsblk -f                      # структура дисків
df -hT                        # вільний простір + тип ФС
sudo fdisk /dev/sdb           # розмітка диска
sudo mount /dev/sdb1 /mnt/x   # монтування
sudo blkid                    # UUID розділів

# Пакети (APT)
sudo apt update && sudo apt upgrade
sudo apt install <pkg>
sudo apt purge <pkg> && sudo apt autoremove
apt show <pkg>
dpkg -L <pkg>                 # файли пакету
dpkg -S <file>                # якому пакету належить файл
ldd $(which <binary>)         # залежності бінарника

# Збірка з коду
./configure --prefix=/usr/local
make -j$(nproc)
sudo make install

# Текстові редактори
nano file.txt                 # Ctrl+O зберегти, Ctrl+X вийти
vim file.txt                  # i — INSERT, Esc — Normal, :wq — вийти
sed -i 's/old/new/g' file     # заміна у файлі
awk -F',' '{print $1}' file   # перший стовпець CSV
```
