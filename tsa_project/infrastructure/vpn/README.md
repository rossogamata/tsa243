# VPN — WireGuard

**Сервер:** `vpn.tsa243.lab` (або суміщений з `gateway.tsa243.lab`)  
**Порт:** UDP 51820  
**Мережа VPN:** `10.10.243.0/24`

---

## Що керує викладач

- Встановлення WireGuard-сервера
- Генерація серверних ключів
- Базова конфігурація `/etc/wireguard/wg0.conf`

## Що робить кожен курсант

1. Генерує власну пару ключів на своїй VM:
   ```bash
   wg genkey | tee privatekey | wg pubkey > publickey
   ```
2. Передає публічний ключ викладачу (або через PR)
3. Отримує свій VPN IP (`10.10.243.1XX`) і конфіг клієнта
4. Налаштовує `wg0.conf` на своїй VM і піднімає інтерфейс:
   ```bash
   sudo wg-quick up wg0
   sudo systemctl enable wg-quick@wg0
   ```
5. Перевіряє: `ping 10.10.243.1` (сервер) і `wg show`

## Peer конфіг на сервері (додається за курсантом)

```ini
[Peer]
# surname
PublicKey = <публічний ключ курсанта>
AllowedIPs = 10.10.243.1XX/32
```

## Навчальний момент

VPN як мережева концепція: шифрований тунель, маршрутизація через нього.
Паралельно з курсом комп'ютерних мереж — реальне застосування теорії.
